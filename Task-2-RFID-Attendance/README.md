# Task 2 – RFID Attendance

## Components

- PIC16F877A
- RFID Reader
- 16x2 LCD
- Green LED
- Red LED
- Buzzer
- UART Virtual Terminal

## Function

The system reads the RFID card number and checks it with the authorized ID.

- Authorized card → Access Granted
- Unauthorized card → Access Denied
- UART → Displays RFID information
- LCD → Displays attendance status
