# Task 1 – Temperature Monitoring

## Components

- PIC16F877A
- LM35 Temperature Sensor
- 16x2 LCD
- LED
- Buzzer
- UART Virtual Terminal

## Function

The system measures temperature using the LM35 sensor and displays it on the LCD.

- Normal temperature → Normal status
- High temperature → Alert with LED and buzzer
- UART → Displays temperature information
