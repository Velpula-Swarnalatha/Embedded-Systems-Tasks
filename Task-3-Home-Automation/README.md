# Task 3 – WhatsApp-based Home Automation System

## Components

- PIC16F877A
- 16x2 LCD
- Light LED
- Fan LED
- UART Virtual Terminal

## Function

The system receives commands through UART to control home appliances and display their status on the LCD.

- LIGHT ON/OFF → Controls Light
- FAN ON/OFF → Controls Fan
- STATUS → Displays device status
- TEMP → Displays temperature


## Implementation Status

Task 3 demonstrates the basic home automation setup, LCD status display, UART command handling, and temperature monitoring in Proteus.

Some appliance control outputs and UART responses are still under development. Task 3 is included as an incomplete implementation to demonstrate the current progress.
