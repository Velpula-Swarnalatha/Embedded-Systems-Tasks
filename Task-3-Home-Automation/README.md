# Task 3 – Home Automation

## Components

- PIC16F877A
- 16x2 LCD
- Light LED
- Fan
- Green LED
- Red LED
- Buzzer
- LM35 Temperature Sensor
- UART Virtual Terminal

## Function

The system receives commands through UART to control the light and fan and display their status on the LCD.

- LIGHT ON/OFF → Controls Light
- FAN ON/OFF → Controls Fan
- STATUS → Displays device status
- HELP → Displays available commands
- TEMP → Displays temperature
